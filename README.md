# Модуль формирования приказа на премирование в 1С:ЗУП

## Описание проекта

Внешняя обработка для 1С:Зарплата и управление персоналом, которая автоматизирует подготовку приказов на премирование сотрудников.

Пользователь выбирает организацию, задаёт период премирования, отмечает сотрудников – система автоматически формирует готовый приказ с возможностью предпросмотра и сохранения на компьютер.

---

## Цель проекта

Заменить ручную подготовку приказов единым автоматизированным сценарием: от выбора сотрудников до получения итогового документа в формате HTML.

---

## Функциональные возможности

- Выбор организации из справочника 1С
- Задание периода премирования
- Загрузка актуального списка сотрудников (из регистра кадровой истории)
- Отметка сотрудников для включения в приказ
- Формирование приказа в формате HTML
- Предпросмотр документа перед сохранением
- Сохранение файла на компьютер (с выбором пути)

---

## Статус разработки

В текущей версии модуля реализован основной функционал: загрузка сотрудников, выбор, формирование приказа и сохранение.

**Данные о проценте и размере премии** в приказе заполняются мок-данными (заглушками):
- Процент премии: 10% (временно)
- Размер премии: 10 000 руб. (временно)

В финальной версии механизм получения данных о премировании будет доработан. Планируется интеграция с регистром сведений для хранения процентов премии по каждому сотруднику.

---

## Установка и запуск

1. Скачайте файл `ФормированиеПриказаНаПремированиеСотрудников.epf`
2. Откройте 1С:ЗУП в режиме пользователя
3. Выберите **Файл → Открыть** и укажите файл обработки
4. Настройте параметры и сформируйте приказ
